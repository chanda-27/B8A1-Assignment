## TypeScript Assignment

# Overview
This repository holds solutions to TypeScript programming problems and notes blogs about TypeScript concepts.

# Contents
(A) solutions.ts — Precise solutions to the programming problems.

(B) type-vs-interface.md — A comparison of Type Aliases and Interfaces.

(C) type-narrowing.md — An explanation of Type Narrowing in TypeScript.


# Requirements
(1) Node.js
(2) TypeScript


# How to Run

(1) Install Node.js.

(2) Install TypeScript using npm: npm install -g typescript
(3) Compile the TypeScript file:tsc solutions.ts
(4) Execute the generated JavaScript file with Node.js:
(5) node solutions.js
